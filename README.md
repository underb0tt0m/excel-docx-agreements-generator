# Автоматизация генерации договоров из Excel

Внутренний Python-инструмент для автоматической генерации договоров (DOCX)  
на основе таблицы Excel с данными контрагентов.

Проект изначально разрабатывался для решения реальной рабочей задачи.

---

## Запуск

```bash
python main.py --file "/полный/путь/к/Данные.xlsx"
```

---

## Задача

Есть Excel-файл, в котором:

- каждая колонка - отдельный контрагент;
- строки содержат:
  - технические ключи (невидимые для пользователя),
  - человеко-читаемые названия полей,
  - значения;
- отдельными строками задаются флаги:
  - нужно ли генерировать соглашение БРД;
  - нужно ли генерировать соглашение ЭДО;
  - тип контрагента (Сервис / Услуга).

Необходимо:
- выбрать только тех контрагентов, для которых требуется генерация документов;
- проверить корректность данных;
- подставить данные в DOCX-шаблоны;
- сохранить готовые договоры в структурированном виде.

---

## Возможности

- Чтение мастер-Excel с произвольным количеством контрагентов
- Управление генерацией через флаги в Excel
- Валидация данных через **Pydantic**
- Условная валидация (например, поля сервиса обязательны только для типа "Сервис")
- Генерация DOCX-документов через **docxtpl**
- Поддержка нескольких шаблонов договоров
- Обработка ошибок без остановки всего процесса

---

## Обезличенные данные и шаблоны

Инструмент разрабатывался для внутреннего использования, поэтому реальные:
- данные контрагентов,
- шаблоны договоров,
- карточки сервисов и услуг

не публикуются в репозитории.

Для размещения проекта в открытом доступе шаблоны были обезличены и сокращены до минимального примера:
- структура плейсхолдеров и формат подстановки сохранены;
- содержимое заменено на нейтральные/демонстрационные данные.
